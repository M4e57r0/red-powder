# ТЗ: модуль «Красный порох» (red-powder)

## 1. Цель
Модуль для Foundry VTT v13.351 / dnd5e 5.2.5: мастер накладывает на персонажей
игроков ступени истощения вручную или по таймеру; игроки снимают истощение,
«выкуривая» сигареты «Красный порох» из инвентаря. Дополнительно: сортировка
навыков на листе персонажа.

## 2. Окно мастера («Панель истощения»)
### 2.1 Открытие
- Кнопка в левой панели инструментов (Scene Controls), видна **только GM**
  (game.user.isGM). Иконка: fa-smoking или fa-hourglass. Нажатие открывает/закрывает окно.
- Окно: ApplicationV2, изменяемый размер, перетаскиваемое, позиция и размер
  запоминаются.

### 2.2 Содержимое окна
**Зона персонажей (drop zone)**
- Мастер перетаскивает в неё Actor из боковой панели Actors. Принимаются
  только актёры type === "character". Остальные отклоняются с уведомлением.
- Дубликаты не добавляются.
- Для каждого актёра строка: портрет, имя, **текущий уровень истощения**,
  **число сигарет** (read-only), кнопки «−1», «+1», «убрать из списка».
- Список (UUID актёров) хранится в world-настройке и сохраняется между сессиями.
  Если актёр удалён, строка помечается как недоступная и может быть удалена.

**Таймер**
- Поля: значение интервала (число > 0), единица (минуты / часы).
- Режим: «Реальное время» или «Игровое время» (game.time.worldTime).
  По умолчанию реальное.
- Чекбокс «Повторять» (по умолчанию включён): после срабатывания таймер
  перезапускается. Если выключен, останавливается.
- Кнопки: Старт, Пауза, Сброс. Отображается оставшееся время (ЧЧ:ММ:СС),
  обновление раз в секунду.
- Состояние таймера хранится в world-настройке как timestamp окончания
  (endsAt), а не как счётчик, чтобы пережить перезагрузку страницы.
- Таймер работает только на клиенте GM. Если при загрузке GM срок уже истёк,
  применяется ровно одно срабатывание, таймер перезапускается, GM получает
  уведомление «пропущено срабатывание».
- Для игрового времени используется хук updateWorldTime, а не setInterval.

**Ручное применение**
- Кнопка «Наложить истощение сейчас»: +1 уровень всем персонажам из списка.
- Опционально шаг (1 по умолчанию, настройка модуля).

### 2.3 Применение истощения
- Единая функция applyExhaustion(actor, delta). Источник истины:
  `actor.system.attributes.exhaustion` в dnd5e 5.2.5. **Агент обязан
  подтвердить это по исходникам системы** и использовать штатный механизм
  (включая статус-эффект), не изобретая свой.
- Уровень ограничивается диапазоном 0…максимум. Максимум по умолчанию 5.
  Настройка «Разрешить смертельный (6-й) уровень» по умолчанию выключена: при
  попытке дойти до 6 уровень не повышается, GM получает предупреждение.
- Каждое изменение пишет сообщение в чат (настройка: публично / только GM /
  выключено): «Имя: истощение N → M» и причина (таймер / вручную / сигарета).

## 3. Сигареты «Красный порох»
### 3.1 Модель данных
- Предмет «Красный порох» = **пачка**: количество (`system.quantity`) — число
  пачек. Заряды (`system.uses`) — число сигарет в текущей пачке; max — размер
  пачки (например 12).
- Предмет определяется флагом flags["red-powder"].cigarette или по имени
  (настройка).
- Всего сигарет у актёра = сумма по подходящим предметам:
  если quantity ≥ 1: (quantity − 1) × max + текущие заряды; иначе 0.

### 3.2 Расход («Выкурить»)
1. Выбрать подходящий предмет с сигаретами > 0.
2. Если текущие заряды > 0: заряды −1.
3. Иначе, если quantity > 1: quantity −1 и заряды = max, затем заряды −1.
4. Истощение −1, сообщение в чат.
5. Если сигареты закончились полностью, предмет не удаляется
   (настройка «Удалять пустую пачку» по умолчанию выключена).
- Изменение зарядов делается через поле, которое использует dnd5e 5.2.5
  (агент подтверждает по исходникам, скорее всего system.uses.spent), а не
  через вычисляемое value.
- Нельзя ломать штатную обработку зарядов dnd5e (autoDestroy и т.п.): агент
  проверяет, не сработает ли она автоматически при расходе последнего заряда,
  и учитывает это.

### 3.3 Индикатор и панель мастера
- Везде показывается «всего сигарет» по формуле из 3.1, а не quantity.
- Кнопка «Выкурить» неактивна, если сигарет = 0 или истощение = 0.

## 4. Сортировка навыков
- Выпадающий список/кнопка в заголовке секции навыков на листе персонажа.
- Режимы: **Стандартный** (исходный порядок dnd5e — в 5.2.5 это алфавитный
  порядок по локализованному названию) и **По характеристике**
  (порядок STR, DEX, CON, INT, WIS, CHA; внутри группы по алфавиту).
  Режим «По алфавиту» не нужен: он совпадает со «Стандартным».
- Характеристика навыка берётся из данных актёра
  (`actor.system.skills[key].ability`), чтобы учитывать переопределения.
- Хранение выбора: client-настройка пользователя (на всех персонажей). Агент
  может предложить per-actor флаг, но реализовать только то, что здесь указано.
- Реализация: переупорядочивание DOM-элементов навыков при каждом рендере
  листа. Исходный порядок запоминается (data-атрибут) для режима «Стандартный».
- Не ломать работу листа: клики, подсветку, бросок навыка и скролл.

## 5. Настройки модуля
World (GM): состояние панели, максимум истощения, разрешить 6-й уровень,
шаг, режим чата, название предмета-сигареты, удалять пустой стак.
Client: режим сортировки навыков.

## 6. Нефункциональные требования
- Foundry v13.351, dnd5e 5.2.5, без зависимостей.
- Локализация ru + en.
- Модуль не ломает лист при отсутствии сигарет или пустом списке.
- Стили в styles/red-powder.css, с префиксом `.red-powder`, поддержка
  тёмной темы Foundry, переменные CSS Foundry.

## 7. Критерии приёмки
1. Кнопка видна только GM; окно открывается и закрывается.
2. Перетаскивание персонажа добавляет его; NPC отклоняется; список переживает
   перезагрузку.
3. Таймер 1 минута в реальном времени: через минуту +1 истощение всем в списке,
   пауза и сброс работают, перезагрузка страницы не сбрасывает таймер.
4. Кнопка «Наложить сейчас» работает.
5. У игрока на листе виден счётчик сигарет, он обновляется при изменении
   количества предмета.
6. «Выкурить»: −1 сигарета, −1 истощение; при 0 сигарет или 0 истощения кнопка
   неактивна.
7. Два режима сортировки навыков работают и сохраняются после перезагрузки.
8. Нет ошибок в консоли F12 при обычной работе.

## 8. Вне рамок
Автоматические эффекты, не заложенные системой dnd5e; компендиумы; интеграция
с другими модулями.
