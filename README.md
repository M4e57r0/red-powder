# Красный порох (red-powder)

Модуль для Foundry VTT: мастер накладывает на персонажей ступени истощения
вручную или по таймеру, а игроки снимают истощение, «выкуривая» сигареты
«Красный порох» из инвентаря. Дополнительно — сортировка навыков на листе
персонажа.

## Требования

- Foundry VTT **13.351**
- Система **dnd5e 5.2.5**
- Без внешних зависимостей

## Установка

1. Скопируйте папку модуля в `Data/modules/red-powder`.
2. Включите модуль в настройках мира (Manage Modules).

## Возможности

### Панель истощения (только мастер)

- Кнопка **«Панель истощения»** (иконка сигареты) в левой панели инструментов,
  видна только GM. Нажатие открывает/закрывает окно.
- **Список персонажей**: перетащите персонажа из панели Actors в зону списка
  (принимаются только актёры типа «Персонаж»). Для каждого — портрет, имя,
  текущее истощение, число сигарет, кнопки «−1», «+1», «убрать». Список
  сохраняется между сессиями.
- **Таймер**: интервал (минуты/часы), режим «реальное»/«игровое» время,
  «Повторять», кнопки Старт/Пауза/Сброс и оставшееся время. Состояние
  переживает перезагрузку страницы; если срок истёк при загрузке, применяется
  ровно одно срабатывание.
- **«Наложить сейчас»** — вручную повышает истощение всем персонажам из списка
  на заданный шаг.

### Сигареты «Красный порох»

- Предмет считается сигаретой, если у него есть флаг
  `flags["red-powder"].cigarette === true` или его имя совпадает с настройкой
  «Название предмета-сигареты» (без учёта регистра).
- **Модель данных**: предмет — это пачка. `system.quantity` — число пачек,
  `system.uses` — заряды: `max` — размер пачки (например 12), `spent` —
  выкуренные сигареты в текущей пачке. Всего сигарет:
  `(quantity − 1) × max + (max − spent)`.
- **Счётчик** «всего сигарет» виден на листе персонажа в сайдбаре (владельцу и
  GM) и обновляется при изменении предметов.
- **Кнопка «Выкурить»** — в строке валюты вкладки «Инвентарь», видна владельцу.
  Активна, только если есть сигареты и истощение > 0. По нажатию: −1 сигарета
  (с автоматическим переходом к следующей пачке), −1 истощение, сообщение в чат.

### Сортировка навыков

- Иконочная кнопка в заголовке блока «Навыки» на листе персонажа. Клик
  переключает режим по кругу:
  - **Стандартный** (`fa-list`) — исходный порядок dnd5e;
  - **По алфавиту** (`fa-arrow-down-a-z`);
  - **По характеристике** (`fa-arrow-down-short-wide`) — STR, DEX, CON, INT, WIS,
    CHA; внутри группы по алфавиту.
- Выбор хранится в client-настройке пользователя и применяется ко всем
  персонажам.

## Настройки

**Мир (GM):**

| Настройка | Описание |
|---|---|
| Максимум истощения | Верхняя граница уровня (1–6) |
| Разрешить смертельный (6-й) уровень | Если выключено, выше максимума не поднимает |
| Шаг ручного наложения | На сколько уровней повышает кнопка «Наложить сейчас» |
| Сообщения в чат | Публично / только мастеру / выключено |
| Название предмета-сигареты | Имя предмета, считающегося сигаретой |
| Удалять пустую пачку | Удалять предмет, когда все сигареты выкурены |

**Клиент:**

| Настройка | Описание |
|---|---|
| Сортировка навыков | Стандартный / по алфавиту / по характеристике |

## Как настроить предмет-сигарету

1. Создайте предмет типа **Расходуемый** (consumable) с именем «Красный порох»
   (или любым, совпадающим с настройкой).
2. В разделе **Uses** задайте `max` = размер пачки (например 12).
3. `quantity` — число пачек.
4. При желании поставьте флаг `flags["red-powder"].cigarette = true`, чтобы
   предмет определялся независимо от имени.

## Локализация

Русский и английский (`lang/ru.json`, `lang/en.json`).

## Структура

```
scripts/
  main.mjs               точка входа, кнопка GM
  constants.mjs          ID, ключи настроек, флаги, константы
  settings.mjs           регистрация настроек
  exhaustion.mjs         applyExhaustion, ограничения, сообщения в чат
  timer.mjs              таймер панели (реальное/игровое время)
  cigarettes.mjs         подсчёт и «выкуривание» сигарет
  sheet-integration.mjs  счётчик и кнопка «Выкурить» на листе
  skill-sort.mjs         сортировка навыков на листе
  apps/exhaustion-panel.mjs  окно панели мастера (ApplicationV2)
templates/               Handlebars-шаблоны
styles/red-powder.css    стили (префикс .red-powder)
lang/                    локализация ru/en
docs/                    ТЗ, этапы, заметки по исходникам
```
